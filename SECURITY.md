# Security & Privacy Policy

## Reporting
Please report vulnerabilities, or any accidental exposure of personal or health data, **privately** via GitHub "Report a vulnerability" (Security → Advisories). Do not open a public issue.

## Scope
The app is designed to run on 127.0.0.1 only. Exposing it to a network, or committing recordings, is outside its intended use.

## Updates
Dependabot alerts are enabled; dependency updates are reviewed via pull requests.
