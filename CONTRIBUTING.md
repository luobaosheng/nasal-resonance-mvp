# Contributing

Thanks for your interest! This is a **research and education aid, not a diagnostic tool**.

## Privacy rules (mandatory)
- **Never** commit or attach audio of patients or any other real person, names, hospital IDs, dates of birth or any other health information. This goes for issues, PRs, screenshots and logs too.
- Use the synthetic generator (`python -m nasal_mvp demo`, `demo-stereo`) for examples and tests.
- Clinical data may only be collected under ethics approval and informed consent, and stays at the collecting clinic.

## How to contribute
1. Open an issue first (bug, feature, or clinical collaboration).
2. Fork, create a branch, keep changes small.
3. Open a pull request using the template; `main` is protected and changes go through PRs.
4. Do not describe features as a "nasalance score" or a diagnosis; use the README wording.

## Clinical collaborators
Speech-language pathologists and cleft speech teams are very welcome. Please use the "Clinical collaboration" issue template. Don't include patient information.
